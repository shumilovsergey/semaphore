## inventory-cli

С увеличением числа серверов стало утомительно вручную создавать файлы в servers/...yml и массово назначать роли. Утилита автоматизирует этот процесс. По мере необходимости функционал будет расширяться.

Запуск:

```bash
cd inventory-cli
docker compose run --build --rm cli
```
